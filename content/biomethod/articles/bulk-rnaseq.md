## 定义解释

Bulk RNA-seq 可以先理解成“给一份混合样本里的各个基因做表达量盘点”。一个样本通常含有很多细胞，最终得到的是这些细胞合在一起的表达信号。我们把不同条件下的样本放在一起，依次回答三个问题：样本整体关系怎么样，哪些基因发生变化，这些变化可能涉及哪些功能。

工作站从整理好的基因 Count 表和样本分组表开始。拿到 FASTQ 的读者，需要先完成测序质量检查、比对或定量，再整理基因计数。这样，进入工作站时，每一列表达值都有明确的样本身份。

## 分析原理

### 为什么要分步骤做

可以把分析想成先核对账本，再比较收支，最后解释变化。样本标签对应错了，后面的计算会一直沿用这个错误；对比方向写反了，上调和下调的解释也会跟着反过来。所以先整理输入，再检查整体模式，然后做差异模型和功能分析。

例如，手里有 3 个对照和 3 个处理样本。PCA 发现处理组有一个样本偏远，你先查实验记录，发现它来自另一个建库日期。接下来要评估批次与组别能否区分，再决定模型设计，而不是直接删除这个样本。

### 同一张差异表，为什么有不同的下游分析

假设完整结果有 15,000 个基因，其中按预设规则选出 300 个候选。ORA 会问这 300 个候选里某类功能成员是否偏多；GSEA 会沿 15,000 个基因的完整有效排序寻找集中变化的集合；热图则帮助你查看选定成员在各样本里的表达模式。每种方法回答的问题不同，适合放在一起互相补充。

## 分析操作

### 先准备两张能对应上的表

Count 表每行一个基因，每列一个样本，保留唯一基因编号。分组表每行一个样本，写清样本名、组别，以及分析需要的批次或配对信息。比如 Count 里一列叫 `Control_1`，分组表里也应使用同一个名称；检查空格、大小写和重复名称。

Count 应为非负整数。若拿到的是 TPM、FPKM 或 log2 CPM，先确认数据来源，再选择适合的数值矩阵工具或相应模型。两套使用 log2 CPM 的内置 GEO 示例已有 limma 差异表，可从已有结果继续做下游分析。

### 在工作站里怎样一步步走

1. 进入 Bulk 自动流程，选择输入，核对物种、对照组与实验组。
2. 在参数阶段选好整套图使用的风格；后续步骤会继承这个选择。
3. 检查低表达过滤、模型设计与 PCA 参数，运行后先看样本名和分组。
4. 确认差异分析方向，保存完整 DEG 表；再按研究问题选择火山图和热图。
5. 选择 GO、KEGG、GSEA 或 GSVA，核对基因集来源、编号、匹配率和各自输入。
6. 需要互作网络时提供相应参考关系；逐步审核结果，最后挑图、组图并导出。

### 怎样知道该回到哪一步

发现分组错误，回到输入和设计；发现通路匹配少，回到物种、基因编号与注释库；只是点太小、字太挤，可用“仅重新绘图”。更改样本、过滤阈值或基因集，会改变分析对象，需要重算相应步骤。

若批次和条件完全重合，比如对照全在第一天、处理全在第二天，模型难以把两种影响分开。此时需要补充实验设计或降低解释范围。换颜色解决不了这个设计问题。

### 读结果和保留记录

按“样本检查 → 完整差异表 → 表达模式 → 功能成员”的顺序看。记录输入版本、过滤阈值、比较方向、基因集来源和软件版本。功能富集提供转录层面的线索，后续可围绕具体成员安排实验验证。

## 适用范围

适合人和小鼠、分组清楚且有生物学重复的 Bulk RNA-seq。混合组织的表达变化可能同时来自细胞比例变化和细胞内表达变化，解读时结合组织与实验背景。配对、时间、剂量或复杂批次设计，需要让模型与研究问题对应。
