# 工作站分析、保存与独立脚本导出

本次沿用 R Shiny、原生 JS/CSS 与独立 R worker；知识库的只读业务不变。

## 使用入口

- 设置 → 示例数据 → 下载数据：打包当前数据集在本机提供的全部文件。GEO 示例包含整理后的输入、完整 DEG、说明及预设；不把整理后的矩阵宣称为 FASTQ，也不为没有 Count 的示例伪造 Count。通用合成示例同时包含各工具所需矩阵、分组、基因集、注释和网络输入。
- 设置 → 保存设置：粘贴绝对地址或浏览本地文件夹。完成的任务复制为 `BioWorkbench-任务ID` 子目录，原始任务目录继续保留。留空则仅保留原任务目录。
- 自动化分析设置页：必须先选本次科研配色；各阶段默认继承，可单独调整。前端黑夜/亮色主题与科研出图配色仍是两个独立选项。
- 火山图：每次导出 `horizontal` 和 `vertical` 子目录，分别包含互换横纵轴的两种视图。目的基因支持逐行文本与单列 CSV/TSV/TXT/XLSX 合并输入，按 gene_id 或 gene_name 精确匹配；默认红字、黄点，样式区可分别改色。额外的显著基因标签开关不会隐藏目的基因。完整匹配报告包含未匹配记录。
- 表达热图 → 热图类型 → 带通路注释的热图；原“通路注释与差异表达”入口也接入相同实现。自动化流程的热图阶段使用同一组控件与算法。

## 通路注释热图

自动模式选择 GO、KEGG、Reactome 或本地 GMT，逐行输入目的通路正式名称/稳定 ID，或上传单列/单行名称表。含空格的通路名不拆词；名称与 ID 不区分大小写，其余内容精确匹配。未匹配时明确报错，不用模糊相似条目替代。GO 使用本机注释包；KEGG/Reactome 初次使用可能需要下载公共参考，缓存沿用既有机制。

手动模式先下载 CSV 模板。模板有四列：编号、基因名、通路名、是否纳入注释。编号填写 DEG 的稳定 gene_id，并非任意流水号；留空时按基因名匹配。开关接受 TRUE/FALSE、1/0、是/否，空值按纳入处理。兼容旧 Excel `GeneAnnotation` 工作表的 GeneKey/Pathway/Use。重名歧义、编号与名称冲突、未匹配和排除记录写入 `annotation_match_report.csv`。

目标注释与完整 DEG、处理后表达矩阵按稳定基因 ID 汇总为 `annotated_expression.csv`，保留统计值和每个样本表达量。目的基因按注释选择，不强制要求显著；最多基因数控制图的规模。同一基因属于不同通路时可重复展示，不对表达量重复相加。

“按通路分块，块内按表达模式聚类”默认开启。开启时保证同一通路相邻，在各块内部使用所选距离/连接算法；关闭后按表达全局聚类。行列聚类和行列反转分别控制。Ward.D2 必须配合欧氏距离。原始表达与未截断的行标准化矩阵分别导出。基因名与通路名背景可选择无填充、沿用当前科研配色或统一预设，通路字体大小/字形/颜色可单独调整。

## 流程持久化

保存开关默认开启。进度位于 `app/results/toolbox/workflow/current.rds`，输入快照与选图位于其对应 flow 目录；任务引用受缓存清理保护。提交和完成步骤、跳转与星标变化会保存。刷新或重启后，在自动化分析设置页点击“恢复上次自动化分析”。无需将用户上传临时文件保留在浏览器会话中。

恢复已经完成的步骤、参数、结果和选图；服务停止时未完成的计算标为中断，需重新运行该步。开启保存不表示可以恢复 DESeq2 的内存计算中点。关闭保存停止更新已有进度，不删除既有检查点；确认开始新流程或明确新建流程时替换原进度及其专用快照，原任务结果不删除。

## 独立 R 脚本

`portable_export.R` 从当前科学实现提取本次分析需要的函数及依赖，嵌入同一个 R 脚本。脚本顶部依次为工作目录/R 环境说明、library、输入地址、真实分析参数、图像导出设置；函数之后执行分析、绘图和导出，最后写 sessionInfo。移除后台启动器、Shiny、工作站 source 调用、模型缓存与浏览器编辑器依赖，不需要运行工作站即可分析。

配置快照改用 `config_resolved.txt`，避免将仅含参数的文件误认为可独立运行的 R 分析脚本。导出器仍能读取旧任务的 `config_resolved.R`。

结果 ZIP 的 `03_独立R脚本与输入/` 包含 `reproduce.R` 和 `data/`，分享时一起发送，先将 setwd 改为解压后的脚本目录。单独下载 R 时使用当前任务的本机输入快照绝对路径；跨电脑应使用 ZIP。重绘导出也从原输入重现分析并使用最终样式，不依赖原工作站 render.rds。全流程 ZIP 每步带有自身脚本与输入。所需 R 包仍须安装，R 版本和 sessionInfo 用于核对环境。
