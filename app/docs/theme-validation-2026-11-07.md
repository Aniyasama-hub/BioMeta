# 默认主题与前后端连接检查 — 2026-11-07

## 实施

- 默认主题 night：靛灰、银白、胭脂红；门户使用单独生成的免疫细胞主题插画和工作站原有示例图形预览。
- 系统设置新增“界面风格”：night、verdant 墨绿铜色早期方案、classic 原有暖纸风格，应用后立即反馈并保存。刷新页面与重新启动都会读取本机 settings.json。
- 默认示例选择移入“系统设置 → 示例数据”，同页显示 Markdown 说明并保存选择。分析页仅保留示例开关及当前数据摘要。移除首次加载首页时自动弹出的示例说明。
- 参数文字、输入框、选中态、焦点、悬浮、禁用、运行反馈和窄屏样式统一。通路的常用筛选优先显示，基因集大小、标识类型和指定条目归入高级设置；所有原有输入 ID 与脚本连接保留。
- 分析状态和进度来自现有独立 R worker 的 status.json，显示真实的粗粒度阶段进度；不是按时间伪造的进度。运行中禁用重复运行/重绘；后台原有重复提交保护继续生效。
- 保留取消、日志、结果图表、描述性下载、全部下载和仅重绘。界面主题不改科研绘图配色、输入数据、模型或计算参数。
- 示例图型预览已从运行缓存目录迁入静态资源目录，清理缓存不影响门户。

## 实际验证

使用 app/tests/ui-themes.py（Python Playwright），访问本机真实 Shiny 服务，不拦截请求、不模拟 R worker：

1. 21 个导航入口逐一打开，无 Shiny 输出异常、无 JavaScript 异常。
2. 三套主题实际点击应用；每套刷新后核对主题持久化。
3. 设置中选择第一套 GEO 示例，显示 README，刷新后核对选择仍保留；最后恢复通用合成示例。
4. 门户“开始分析”确实打开 Bulk 流程；搜索 KEGG 能正确筛选工具。
5. KEGG 使用系统合成 DEG 和合成 GMT，实际执行输入检查、提交、运行中重复提交锁定、取消、再次提交、完成、ZIP 下载和仅重绘。
6. 检查 ZIP 内存在 kegg_enrichment.png 与 kegg_enrichment_plot_data.csv；不是概念图片或虚拟下载。
7. 默认主题在 1536×1000 与 390×844 检查；手机宽度没有页面横向溢出。
8. Impeccable detect 对修改的 CSS、JS、R 界面和运行页面执行一次检查，退出码 0，报告 []。
9. R 与 JavaScript 语法检查、git diff --check。

## 边界与说明

本轮实际跑的是合成 GMT 的 KEGG 工具路径，用来验证页面到脚本的执行连接；没有据此声称验证了在线 KEGG 注释库、全部生物学算法或完整 Bulk 全流程，也没有运行用户个人研究数据。三主题切换、分析页和实际合成结果均在浏览器查看。Shiny 包提示由较新 R 小版本构建，本轮执行通过。

测试输出与运行任务继续放在 Git 忽略的缓存/结果目录；不上传个人路径、设置、研究数据或任务结果。只有代码、独立界面资产和设计/验证说明纳入本地版本。
