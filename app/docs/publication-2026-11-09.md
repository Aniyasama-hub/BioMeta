# Beta 发布内容与本机清理

复检后授权发布。公开版本为 0.2.0-beta.1，两个子项目均为 Beta。

工作站内的任务输入快照、结果、公共注释缓存、设置、流程预设与恢复进度、旧发布包、日志、data、本地 PPI 文件、测试产物、Python 缓存、R 历史和机器快捷方式已移出工作站，放入本机私有隔离目录。自动审批禁止永久删除，因此采用可恢复的隔离方式；不把隔离目录上传。工作站外的研究文件、R 与已安装包未清理。

保留程序、第三方许可证、合成示例及有来源说明的九套公开 GEO 示例。新用户首次启动自行选择 R，随后在其本机建立设置和缓存。

公开树不包含开发上下文、快捷方式或缓存产物，不推送本地开发 Git 历史；新提交以官网当前提交为父提交。README 和介绍.md 简要说明定位、功能、配置与操作，更新说明记录实际改动。

下载支持官方 main 的 Code ZIP 和 Git 克隆。本轮未创建 GitHub Releases 条目。此前审查报告中的“等待确认”是历史记录，当前授权以本说明为准。
