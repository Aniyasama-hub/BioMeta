# 0.2.0-alpha.1 常规审查报告

结论：**候选版可在已配置的本机环境试用，暂不建议直接正式发布。** 核心示例脚本和出图已通过，但若干历史测试仍不适配当前交互/输入约定，尚未全绿；全新 Windows 安装未实测。按用户要求先交报告，等待确认后再推进上传。

## 范围和环境

审查从本地 c54a5d2 开始；官网对比基线是 2026-11-09 读取的 main 提交 d950dba8147b6e4ac6e4eee042e98473312eb620。GitHub Releases 查询为空，没有可引用的上一正式发行标签。仓库访问和管理权限可用，但本轮没有推送、创建远程标签或发布 Release。

隔离副本只从 Git 管理的文件复制，不复制个人设置和研究输入。为避免反复下载，复制本机既有公共注释缓存。测试副本位于本机 app/tests/_pathway-review/alpha-audit/workspace，日志在上一级，均被 Git 忽略。没有使用本轮用户研究数据，没有升级 R 包，没有更改原工作站设置或重启原服务。

验证环境 R 4.5.1 / Windows；30 个工作站必需包均可识别。shiny 有“built under R 4.5.3”警告，本轮可运行；不据此保证所有 R 版本兼容。未执行联网依赖安装、更新包、原生文件选择窗口的全新机器安装，也未逐个重新拟合九套 GEO Count。

## 发现、修正与未通过项

1. **实际产品缺陷，已修正**：DEG summary 饼图固定写 PNG，不遵循所选格式。现在按 style$formats 和 DPI 输出，统计不变；独立 DEG 示例复检通过。初轮和复检日志均保留。
2. **旧 smoke 断言，已修正**：仍要求 32 图，双方向火山图使实际四格式图变为 36；各分支已实际生成，复检通过。
3. **旧导出夹具，已修正**：假任务放在任意临时目录，新的独立脚本导出依据任务目录定位 app 导致找不到 config。夹具改放隔离副本真实 jobs 层级；复检通过。未修改生产路径来迁就测试。
4. **旧 integration.R 尚未适配**：仍以 Count 和混杂矩阵同时传给全部下游工具，缺少如今必须的 DEG/VST，并断言 DEG 不生成图片。其历史综合测试未通过，不应称为功能已全绿。当前 22 个独立示例覆盖了实际支持的输入；后续应重写该夹具再关闭这一审查项。
5. **旧平台浏览器断言尚未适配**：已将文章数量由 8 更新为 18，随后仍在 PCA 介绍帖要求代码块，而代码已移至技术帖。该综合测试未通过；当前 editorial-ui 已覆盖新的介绍/技术帖结构和跳转。后续需同步其他旧源码卡片断言。
6. **旧主题长序列测试超时**：在示例 KEGG 的输入检查弹窗等待处超时。另在全新会话以及依次遍历 21 工具后重试，均成功打开弹窗，没有通知报错。目前证据不足以断言生产功能损坏，也不足以将长序列测试算通过；仍需调查异步控件就绪与固定等待时间。
7. **流程浏览器复检仍未通过**：补选必选配色后，默认列表、运行环境下拉、自定义步骤增删和拖动均通过；随后已实际运行示例流程、返回并重跑。到标星图片自动填入组图时，panel_count 已成为 2，第一张缩略图出现，但第二张 `panel_thumb_panel_02 img` 等待 30 秒仍未出现，通知为空。尚未定位是绑定/缓存、渲染还是测试就绪条件的问题；不能称自动组图全流程通过。建议列为发布前优先处理项，截图在 browser/workflow-recheck/failure.png。

以上失败有记录，不通过删除合法入口、关闭映射校验或放宽统计阈值制造通过。版本尚为 Alpha；审查报告不等同所有数据输入和科学结论均正确。

DEG 格式补充测试 `deg-formats.R` 实际只请求 SVG/PDF，并确认两者存在且 PNG 不存在，验证本轮修复确实遵循格式选择，而不是仅重跑默认 PNG。

## 结构、发布和安装交付

ARCHITECTURE.md 整理真实目录职责；没有物理大迁移。shared/platform.json 统一版本和两个 Alpha 标签。RELEASE_NOTES_v0.2.0-alpha.1.md 是对官网提交的更新说明，INSTALL.md 提供 ZIP 和同仓库 Git 标签两种配置方式。app/tools/bootstrap.R 默认检查，仅显式 --install 才安装缺失包，本轮没有执行安装。

候选 ZIP 从 Git 快照生成，不包含研究数据、results、缓存、日志、本机快捷方式、开发上下文和测试目录。开发/历史说明中的示例路径仍是文字，不包含这些路径的文件；正式发布前建议再检查文档的本机示例路径是否需要去标识化。包不捆绑 R，不称为免安装版本。校验和与具体包路径在报告交付时提供。

在用户确认审查结果并确定上述未通过项如何处理前，不改官网 main、不发布 GitHub Release。准备后的下一步是使剩余综合测试与现行功能一致，再在原仓库创建 Alpha prerelease、上传 ZIP/SHA256，并验证从公开 ZIP 和仓库克隆两条路径。
