# 工作站改版与检查记录


## 界面

采用纸色背景、墨绿工具栏、朱红强调色、衬线标题和细线网格。保留清晰的参数标签、单位、状态和错误；删除重复标语、流程口号、格式徽章和大段常驻说明。

工具卡、标题、文件输入及局部参数板块支持悬浮说明。移开鼠标自动收起；Tab 聚焦显示，失焦或 Escape 收起；移动端可点按问号。提示内容按纯文本插入，避免上传字段或说明文本被作为 HTML 执行。

## PPI 修复

- 独立 Node 与 Edge 上传位；默认文件模式不拟合 Count 模型。
- 按 Edge 端点覆盖关系选择节点 ID；支持同时包含 STRING_id 和 gene_id 的节点表，保留原 gene_id。
- 支持 from/to、source/target 等字段；combined_score 默认除以 1000，支持手工指定分数单位。
- 拒绝未知端点、重复节点和非法分数；保留孤立节点，自环及低置信边另表记录；反向重复边保留最高分。
- 固定随机种子的静态布局；离线交互图可拖动、缩放、切换布局和导出 PNG。实际引入 Cytoscape.js MIT 版本，附完整许可证。


## 图型设置

| 图型 | 专属样式 |
|---|---|
| PCA / 火山图 | 散点形状、大小、透明度、标签、坐标版式；分组或显著性颜色；火山图阈值线 |
| 各类热图 / GSVA | 三色阶、边线、行列名字号、列名角度、缺失色、栅格化 |
| GO / KEGG | 气泡或条形，显著性渐变、通路名换行；条形模式隐藏气泡大小 |
| GSEA | 富集曲线、命中刻线、正负排名区域颜色与线宽 |
| PPI | 节点属性着色、节点尺寸、边透明度和线宽、标签数量 |
| Circos | 染色体、区域、连线颜色，间隔、角度及轨道高度 |
| 差异统计表 | 不显示图形样式与格式面板 |

共同保留适用的画布、字体、背景与输出格式；GSEA/Circos 不显示无意义的图例位置。无关参数不参与当前图型的校验。仅 PPI 页面显示交互网络标签页。

## 检查结果

- R 源文件语法检查、JavaScript 语法检查通过。
- 浏览器逐一打开 14 个工具；无界面输出错误、无 JavaScript 异常。
- 浏览器实际上传两张小型 PPI 示例表并提交后台任务：完成；交互图显示 4 个节点，属性颜色正确。
- 悬浮出现、移开消失、键盘聚焦、Escape 收起通过；390px 移动视口无横向溢出。
- 8 条合成绘图路径 × PNG/SVG/TIFF/PDF，共 32 个非空文件：网络、矩阵 PCA、矩阵热图、火山图、富集气泡、富集条形、GSEA、Circos。
- 修复通用矩阵无恒定行时排除表构造失败；修复后端 CSV/TSV 分隔符处理不一致；修复交互网络八位色值导致节点变灰的问题。
- 新旧项目隔离、旧任务记录及数据不覆盖。浏览器和绘图检查均在 staging 中进行。

## 验证边界

没有重跑真实 RNA-seq 拟合、全部 GO/KEGG/GSEA/GSVA 数据库分析，也没有运行完整的旧手工热图分析。14 个工具的界面检查不等于 14 种科学分析的端到端验证。真实数据的科学结论仍由用户运行并审阅。

本工作站覆盖当前列出的 14 个入口，不等于完整复刻 TBtools 的全部工具。导出网络 HTML 需与同目录 JS 一起保留，建议下载结果包。
