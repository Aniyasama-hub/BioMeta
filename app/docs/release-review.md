# v0.1.0 发布前检查

日期：2026-11-05。所有新分析均使用隔离目录中的合成数据，不读取真实科研 Count，不更改原项目或用户已有任务。

## 发现与修正

1. 四处导出逻辑强制补入 PNG，与界面可取消 PNG 的行为冲突。删除补入逻辑，统一遵循所选格式。
2. 旧热图适配器只替换原脚本已存在的配置赋值，新增的背景、图例配置未进入执行环境，两类热图实际运行失败。改为先注入配置，再替换既有赋值；保留算法与布局。
3. 手工热图的快速 VST 要求足够多的基因，小型输入可能失败。改用 varianceStabilizingTransformation。
4. 任务历史直接读取 RDS，单个损坏文件可能使历史列表报错。跳过无法读取的请求记录。

## 可复查命令

在项目根目录将 Rscript 路径替换为实际安装位置后执行：

```powershell
& '<R 安装目录>\bin\Rscript.exe' --vanilla app/tests/smoke.R app
& '<R 安装目录>\bin\Rscript.exe' --vanilla app/tests/integration.R app
```

第二项会实际执行合成分析，并在工作站结果目录产生测试任务；请在独立测试副本中运行。测试产物被 Git 忽略。

## 边界

合成 GMT 仅测试分析链路，不代表真实 GO/KEGG 注释内容。未在本轮验证内置小鼠 GO 数据库的完整实测、所有输入变体、大规模网络或真实科研数据的完整结果。没有将“任务完成”当成真实科学结论正确性的保证。

代码包不包含 R 环境、科研输入、模型缓存、运行结果、日志或机器专用快捷方式。当前面向 Windows 本地单用户使用。
