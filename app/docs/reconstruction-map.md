# TBtools 观察结果与本地 R 重建映射

本次使用 reverse-engineer-anything 工作流，复用此前对本机 TBtools-II 2.486 的发布包、字节码及实际运行证据；现有 R 源码按普通源码工程处理，没有对 R 项目运行无关二进制分析。


| 已观察事实 | R 重建选择 | 边界 |
|---|---|---|
| Swing 主窗口按工具分类组织 JPanel | Shiny 分类导航、工具参数区与结果区 | 重建操作流程，未复制 Java 窗口系统 |
| 输入、分析、图元与导出有可区分的调用层 | UI → 独立 R worker → 计算/准备 → 绘图 | 重写为本地 R 模块；科学设置以本项目参数为准 |
| PCA 使用中心化、可选标准化 | 已处理矩阵使用 prcomp；RNA-seq 先走 VST | 原始 TBtools PCA 和 RNA-seq VST PCA 输入语义不同 |
| 热图控制有行列缩放、距离和聚类 | ComplexHeatmap + 显式准备好的矩阵和树 | 未声称所有 TBtools 缩放方法及默认值一一等价 |
| Circos 使用染色体、特征和区域链接输入 | circlize 重建区域圈图 | 本版采用带表头 CSV 和明确的 0 起点半开坐标 |
| PNG/SVG/PDF/TIFF 分设备导出 | R 设备 + svglite + ComplexHeatmap/ggplot2 | 没有照搬 Java2D 图元或工程文件格式 |
| 插件通过生成 JPanel 动态接入 | 统一工具目录与任务分派函数 | 尚无插件市场或任意上传代码执行接口 |
| 软件有本地 RPC、数据管理等额外模块 | 输入快照、任务日志、缓存及历史 | 没有重建全部 RPC 服务和全套数据库管理 |



此前独立 PCA 实验说明：等权 150 样本的 JSAT 与 R 标准化坐标需对齐主轴符号，并修正总体/样本标准差口径。当前通用矩阵工具采用 R 的样本标准差约定；不隐式施加 TBtools 兼容比例，也不把 RNA-seq VST 结果声称为对 TBtools 原始矩阵工具的数值复刻。

本次新增代码的验证范围为语法、输入契约和界面交互。完整科研分析仍由用户执行，当前未生成新的模型验收结果。
