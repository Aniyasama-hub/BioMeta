# 设置、流程规划与图像编辑第二轮修订

日期：2026-11-08。沿用 R Shiny、独立 R worker 和原生 JavaScript/CSS，没有迁移分析服务或 BioMethod 架构。本轮对应用户的 13 项修改，测试使用小型合成数据。

## 界面与设置

黑夜和亮色使用两张不同构图的首页插画。亮色使用赤陶、鼠尾草绿和纸色，不再通过 screen 混合稀释图片。窄屏把文字与插画上下排列，避免互相覆盖。素材是艺术插画，来源、尺寸和完整提示词见 `app/www/assets/README.md` 与 `hero-v2-prompts.md`。

工作站与 BioMethod 的设置入口统一显示“设置”。运行环境的 Rscript、Python、RStudio 各使用一个配置方式下拉框，包含自动嗅探、浏览本地、手动输入。R、Python、RStudio 和 Bioconductor 官网集中在该页末尾“友情网址”。Bioconductor 仍按所选 R 检测发行版本，不作为可执行文件配置。

软件包页立即列出基本依赖及当前版本，不必先联网才看到表格。联网检测后更新兼容的仓库版本，并把额外已安装包列入第二张同格式表格。缺失的基本依赖会保留在表中；仓库可提供时可通过更新操作安装。检测、批量更新和单包更新沿用独立 R 脚本，更新后再检测。最新版本指与所选 R/Bioconductor 兼容的仓库版本。

## 流程规划与返回修改

导入数据后先选择默认完整流程，或从工作站现有工具中添加、删除、按手柄拖动排序。允许重复使用同一工具，每个实例具有唯一 ID、独立输入、参数和样式。一个流程可有 1–40 步；组图最多出现一次且须放在最后。不需要 Count 的自定义独立工具可以先选流程，再上传其所需输入。

勾选“保存为下次自定义预设”写入本机 `app/results/toolbox/settings.json` 的 `workflow_preset`。当前版本保存一套默认自定义预设，刷新和再次启动时可读取。该配置不在 PNG 临时缓存中，不会随新流程或离开流程删除；本机设置仍被 Git 忽略。

每步依然由用户设置参数后手动运行。进度导航中已到达的步骤可以直接返回，没有“跳过并填写原因”操作。返回本身可以查看原结果；真正重跑后，当前及后续步骤在本次流程中的确认状态、图片缓存和任务关联失效，用户需顺序重新生成后续结果。原任务目录仍保留在历史中。下游自动关联最近一个已确认的前置 DEG，避免引用未重新确认的旧统计结果。

## 选图、上传顺序和输出

点击“下一步”只展示当前步骤的图片，不显示阶段选择、筛选或排序控件。最终组图的“从本次自动化流程挑选”才展示完整阶段顺序，允许按具体步骤、感兴趣状态筛选和按文件大小排序。筛选值使用唯一步骤 ID，显示名称使用编号和工具名，重复工具也能区分。

组图数量上方的复选框会按分析顺序填入标星图片，并同步调整数量。当前画布支持 1–12 张；超过 12 张时明确提示，只填入前 12 张。用户仍可修改数量、上传本地图片或从缓存逐张选择；手动调整会关闭自动填图，以免覆盖正在编辑的顺序。

每个上传栏左侧显示缩略图，左上方提供三横线拖动手柄和置顶/置尾。只有按住手柄才启动排序，可插入另一行的前方或后方；原图片路径、显示名称及大小滑轨随图片一起换位，实际提交给组图脚本的顺序同步改变。删除缓存选入的面板只清除该槽位，不删除原缓存图。

每个阶段结束自动保存 PNG 到会话缓存；PPI 精细编辑可把当前视图加入同一缓存。离开流程、会话结束和新分析开始时清空临时缓存。最终 ZIP 根据实际流程顺序编号文件夹，包含各步骤任务中的输入快照、图、表、日志和复现文件，以及对应 PPI 编辑图片。重新运行前的旧历史任务不重复装入当前流程包。

## PPI 与组图编辑器

PPI 的群集筛选保留“前 N 个簇”，新增“所有簇合计前 N 个节点”。后者为正数时，从满足最小簇大小的所有簇中按节点度排序，取总共 N 个节点；为 0 时沿用簇数量选项。连线只保留选中节点之间原有的簇内边。

组图独立编辑器增加撤销/重做图标，支持 Ctrl+Z、Ctrl+Y 和 Ctrl+Shift+Z。拖动作为一次修改记录；键盘移动、对齐、对称和重置同样可撤销。历史保留最近 100 次，重做在新修改后清空。文本框内保留浏览器原生撤销行为，编辑历史不跨窗口永久保存。

## 通路标签与基因映射

GO/KEGG/GSEA/GSVA 的展示标签清理重复的 `[BP]`、`[CC]`、`[MF]`、`[Reactome]` 与拼写变体 `[recatome]`。只清理图上的显示文本，原始通路编号、统计表和注释来源不变。

参数中的“基因编号与名称映射”提供原始输入列选择；不指定时使用已知标准字段。GSVA 使用逐样本表达矩阵的列，其他通路工具优先读取差异/排序表。Count 模式把显式列选择继续传给原导入逻辑。重复或空编号直接报错，不进行任意合并；名称缺失时保留原编号作为回退标识。

每次通路分析输出 `input_gene_mapping.csv`，公共注释模式另输出 `public_gene_mapping.csv`，记录原始编号、输入名称、Entrez 编号、公共名称及映射状态。不能唯一映射的条目留在报告中并退出公共富集候选；编号和名称都能识别但指向不同基因时拒绝继续。报告不能替代操作者核对物种、数据库版本和未映射条目。
