# f2e-spec 适配自查 — 2026-11-07

本轮按用户要求进行局部自查，没有整体改版或技术栈迁移。后续长期规则已写入项目 AGENTS.md 和 frontend-guidelines.md。

## 修正

1. 任务状态消息过去只更新当时存在的按钮，Shiny 动态插入的新按钮可能遗漏运行中禁用状态。现保留最新执行状态，对工作区新插入的按钮同步；观察限于工作区并按动画帧合并。
2. 点击反馈移除同步读取 offsetWidth 强制布局，改用浏览器动画接口，并尊重减少动画偏好。
3. 主界面与说明页通过 Shiny lang 参数声明 zh-CN；图片排版独立 HTML 补齐显式 head/body。原有画布、数据占位符和导出脚本保持不变。
4. 非关键界面增强脚本采用 defer，保留关键主题初始化和 Shiny 自带依赖顺序。
5. 悬浮提示显隐只增删自身的描述引用，保留已有 aria-describedby。
6. 新主题 CSS 和界面状态 JS 统一格式，补充编辑器与格式化配置。未对旧版全部 CSS、PPI 脚本或第三方库做批量格式化。

7. 设计检测发现排版编辑器“导出 PNG”在悬停时白字叠在浅色底上，局部调整悬停底色以保证可读性。

## 验证

- R/JS 语法、固定版本 Prettier 格式检查、git diff --check。
- 浏览器回归：21 个入口、三主题刷新、示例持久化、实际合成 KEGG 提交/禁重/取消/重跑/完成/下载/重绘、窄屏无横向溢出；无 JavaScript 错误。
- 新增语言/唯一标题、提示描述保留和运行中后插入控件禁用的回归检查。
- 主题样式格式整理前后对浏览器解析规则进行比较，仅 URL 引号和 var 回退逗号空白表示不同；规范化这些表示后规则相同。颜色、布局和已确认主题不变。

本轮没有安装官方 F2ELint/ESLint/Stylelint 全套工具，也未声明全仓库满足上游全部条目。旧代码仍有可逐步整理的格式/优先级问题，按用户要求控制范围；较大的变更今后先给可审核方案再确认。

设计检测同时提示排版编辑器采用暖纸底色；这是保留的原有视觉选择，本轮不因此改版。它是审美提示，不作为编码失败；最终报告保留该提示，不宣称检测完全零问题。
