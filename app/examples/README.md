# 通用合成示例

这是由程序生成的小型练习数据，目的是帮助你熟悉输入格式、尝试参数和检查绘图是否正常。它不是患者或动物实验数据，也不能用来支持真实生物学结论。分析页勾选“示例数据”后，系统会自动填入当前工具需要的预设文件，不必分别上传。

RNA-seq 示例包括原始计数、样本分组、处理后表达矩阵、完整差异结果和目标基因列表；PPI 使用配套节点及连线，富集分析使用配套的小型基因集。桑基图、韦恩图、聚类图、蜜蜂图、雷达图和环形图也各自提供适合其格式的输入表，而不是强行使用 Count。

如果需要探索真实研究背景，可在本菜单改选九套 GEO 示例。每套说明会列出来源、样本构成、默认比较、清洗规则和方法；两套只有归一化表达量的示例差异表使用 limma，其余七套使用 DESeq2。使用自己的数据时取消勾选并上传文件，内置示例不会因此改变。
