# PPI Studio

PPI Studio 是 BioWorkbench 的独立交互编辑子项目。一次 PPI 任务生成两个离线页面，`network.html` 提供画布、布局、标签和基本样式，`ppi-studio.html` 在独立窗口提供分群与枢纽节点分析。任务结果包中的 JavaScript 与许可证应与页面放在同一目录。

点击基础编辑器的「精细编辑」可打开新窗口。精细编辑从该任务保存的网络和样式开始。保留前 N 项后，可以调整布局并导出当前视图 PNG。浏览器操作只影响当前页面。节点间距按比例修改布局坐标，滚轮单独调节视图缩放。「节点风格」同时显示形状名称和图形。「预设配色」色卡依次为节点、画布和连线，自定义颜色按节点度分段。「全局风格」同时修改画布、节点、标签和连线，选择「任务原始样式」可恢复任务样式。算法问号会打开离线说明页。初始标签遵从任务设置，「显示全部标签」和「隐藏全部标签」控制所有节点。

R 后端基于阈值过滤后的无向网络预计算分群和节点指标，浏览器负责排序、筛选与渲染。各方法的公式、边权口径和适用范围可在算法旁的问号查看。结果包括 `ppi_hub_scores.csv` 和 `ppi_communities.csv`。

精确 MCC 仅在节点数不超过 2000 且最大核数不超过 12 时提供。介数与调和中心性仅在节点数不超过 5000 且边数不超过 100000 时提供。超限方法不出现在当前任务的算法菜单中。

方法来源见 [cytoHubba](https://doi.org/10.1186/1752-0509-8-S4-S11)、[Cytoscape Analyzer](https://manual.cytoscape.org/en/stable/Network_Analyzer.html) 和 [igraph](https://r.igraph.org/reference/)。节点风格预设和色条在切换时即时更新，配色包括面向屏幕绘图调整的 NCS 趋势配色与四组本地设计配色。

本机可将 PPI 文件模式示例成对放在 `app/examples/local-ppi/`，命名为 `ppi_nodes.csv` 和 `ppi_edges.csv`。该目录由 Git 忽略，缺少任一文件时使用仓库的合成示例。
